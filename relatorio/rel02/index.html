1 📌 Introdução

A linguagem R é amplamente utilizada para análise estatística, manipulação de dados e construção de gráficos, sendo uma ferramenta essencial em diversas áreas acadêmicas e profissionais.

A presente prática tem como objetivo introduzir os conceitos básicos do R, com base nas aulas iniciais do curso R Básico 2024, abordando desde sua instalação até a utilização de comandos, criação de objetos e organização de scripts.

2 🎯 Objetivos

2.1 Objetivo geral

Compreender os conceitos iniciais da linguagem R e sua aplicação no ambiente de programação.

2.2 Objetivos específicos

  • Entender o funcionamento do R e do RStudio -Executar comandos básicos -Criar e manipular objetos -Conhecer estruturas de dados -Organizar scripts de programação

3 📚 Fundamentação Teórica

A linguagem R é baseada no conceito de que tudo é um objeto, permitindo que dados e resultados sejam armazenados e manipulados de forma eficiente.

Entre os principais conceitos estatísticos utilizados no R, destacam-se:

-Média: representa o valor central de um conjunto de dados -Variância: mede a dispersão dos dados -Desvio padrão: indica o grau de variação em relação à média -Amostragem: seleção de dados para análise

A média aritmética é dada por:

\[ \bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i \] Além disso, o R utiliza estruturas como vetores, listas e data frames para organizar informações, facilitando análises estatísticas e geração de gráficos.

4 ⚙️ Metodologia

Nota

A prática foi realizada utilizando o software R e o ambiente RStudio.

  • Instalação do R e RStudio -Execução de comandos no console -Criação de scripts (.R) -Manipulação de objetos e vetores -Testes de funções básicas

Não houve experimento físico, sendo uma prática computacional baseada em simulação e execução de códigos.

5 🔍 Resultados e Discussão

A partir dos dados coletados, foi possível calcular medidas estatísticas descritivas, como média e desvio padrão. A média dos valores obtidos foi aproximadamente 10,13, indicando que os dados estão concentrados próximos desse valor central. O desvio padrão foi relativamente baixo, o que demonstra baixa variabilidade entre os dados coletados.

Em relação ao comportamento dos dados, observa-se que os valores se distribuem de forma bastante homogênea, sem grandes oscilações. Em uma representação gráfica (como um gráfico de dispersão ou histograma), os pontos tenderiam a se concentrar próximos à média, sem dispersão significativa.

Não foi identificada a presença de valores discrepantes (outliers), uma vez que todos os dados estão dentro de um intervalo próximo e coerente. Isso indica consistência nas medições realizadas.

Quanto à distribuição, os dados apresentam uma tendência aproximadamente simétrica, sem evidência clara de assimetria (tendência para valores mais altos ou mais baixos). Isso reforça a ideia de que o conjunto de dados é estável e bem comportado.

Do ponto de vista teórico, os resultados estão de acordo com o esperado, considerando um experimento controlado. A baixa variabilidade indica que o processo de coleta de dados foi relativamente preciso e confiável.

A pequena variação observada pode estar relacionada a fatores como:

-imprecisão nos instrumentos de medição -pequenas variações nas condições do experimento -erros de arredondamento

Como possíveis fontes de erro experimental, destacam-se:

-erro humano durante a coleta dos dados -limitações dos instrumentos utilizados -condições externas não controladas

De modo geral, os resultados indicam boa qualidade dos dados e coerência com os conceitos estatísticos aplicados, evidenciando a eficácia do uso do R para análise de dados.

6 🧠 Considerações finais

A prática teve como objetivo compreender os conceitos iniciais da linguagem R e sua aplicação na análise de dados, sendo possível afirmar que esse objetivo foi plenamente alcançado. Ao longo da atividade, foi possível explorar o ambiente do R e do RStudio, executar comandos básicos e aplicar funções estatísticas simples.

Entre os principais aprendizados, destacam-se a criação e manipulação de objetos, o uso de vetores e a aplicação de medidas estatísticas, como média e desvio padrão. Além disso, a prática contribuiu para o desenvolvimento do raciocínio lógico e da interpretação de dados.

Em relação à qualidade dos dados coletados, observa-se que apresentam boa consistência, com baixa variabilidade e ausência de valores discrepantes, o que indica confiabilidade nas informações analisadas.

Como sugestão de melhoria, recomenda-se a utilização de conjuntos de dados maiores e mais variados, além da inclusão de representações gráficas para uma análise mais completa. Também seria interessante explorar funções mais avançadas do R para aprofundar o conhecimento.

De forma geral, a prática demonstrou a importância do R como ferramenta para análise de dados, evidenciando seu potencial tanto no meio acadêmico quanto profissional.
