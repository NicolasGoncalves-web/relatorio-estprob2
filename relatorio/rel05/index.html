1 📌 Introdução

  • O estudo das distribuições de probabilidade é um dos pilares da estatística, pois permite modelar fenômenos aleatórios e compreender a variabilidade natural dos dados. Entre as distribuições mais utilizadas estão a Binomial, a Poisson e a Normal, cada uma com aplicações específicas em diferentes áreas do conhecimento.

  • A Distribuição Binomial é aplicada em situações de experimentos com número fixo de tentativas e probabilidade constante de sucesso. Já a Distribuição de Poisson é utilizada para modelar o número de ocorrências de um evento em um intervalo de tempo ou espaço. A Distribuição Normal, por sua vez, é a mais importante em estatística, pois descreve variáveis contínuas e está presente em inúmeros fenômenos naturais e sociais.

  • Em muitos casos, cálculos envolvendo Binomial ou Poisson podem ser complexos quando os parâmetros são grandes. Nesses cenários, torna-se útil aproximar essas distribuições pela Normal, simplificando os cálculos e permitindo o uso de tabelas e softwares estatísticos. Essa aproximação é justificada matematicamente e possui grande relevância prática, especialmente em análises de grandes amostras.

  • Neste relatório, serão apresentadas as condições de aproximação da Binomial e da Poisson à Normal, as demonstrações matemáticas que sustentam essa equivalência e exemplos práticos de aplicação utilizando o software RStudio.

3 📚 Fundamentação Teórica

3.1 Distribuição Binomial → Normal

  • Condição de aproximação: Quando (n) é grande e (p) não é muito próximo de 0 ou 1.
  • Teorema:
    Se (X Binomial(n,p)), então para (n) grande:

[ X Normal(= np, ^2 = np(1-p)) ]

  • Exemplo aplicado:
    (n = 100), (p = 0.3).
    Aproximação: (Normal(= 30, ^2 = 21)).
Código 
n <- 100; p <- 0.3
x <- 20:40
binom <- dbinom(x, size=n, prob=p)
norm <- dnorm(x, mean=n*p, sd=sqrt(n*p*(1-p)))
plot(x, binom, type="h", lwd=2, col="blue", main="Binomial vs Normal")
lines(x, norm, col="red", lwd=2)
legend("topright", legend=c("Binomial", "Normal"), col=c("blue","red"), lwd=2)

Distribuição Poisson → Normal Condição de aproximação: Quando 𝜆 é grande.

Teorema: Se 𝑋 ∼ 𝑃 𝑜 𝑖 𝑠 𝑠 𝑜 𝑛 ( 𝜆 ) , então para 𝜆 grande:

𝑋 ≈ 𝑁 𝑜 𝑟 𝑚 𝑎 𝑙 ( 𝜇 = 𝜆 , 𝜎 2 = 𝜆 ) Exemplo aplicado: 𝜆 = 50 . Aproximação: 𝑁 𝑜 𝑟 𝑚 𝑎 𝑙 ( 𝜇 = 50 , 𝜎 2 = 50 ) .

Código 
lambda <- 50
x <- 30:70
pois <- dpois(x, lambda=lambda)
norm <- dnorm(x, mean=lambda, sd=sqrt(lambda))
plot(x, pois, type="h", lwd=2, col="green", main="Poisson vs Normal")
lines(x, norm, col="red", lwd=2)
legend("topright", legend=c("Poisson", "Normal"), col=c("green","red"), lwd=2)

## 📚 Fundamentação Teórica

### Distribuição Binomial → Normal

- **Condição de aproximação**: Quando \(n\) é grande e \(p\) não é muito próximo de 0 ou 1.  
- **Teorema**:  
  Se \(X \sim Binomial(n,p)\), então para \(n\) grande:  
  

\[
  X \approx Normal(\mu = np, \sigma^2 = np(1-p))
  \]



- **Exemplo aplicado**:  
  \(n = 100\), \(p = 0.3\).  
  Aproximação: \(Normal(\mu = 30, \sigma^2 = 21)\).

```{r}
n <- 100; p <- 0.3
x <- 20:40
binom <- dbinom(x, size=n, prob=p)
norm <- dnorm(x, mean=n*p, sd=sqrt(n*p*(1-p)))
plot(x, binom, type="h", lwd=2, col="blue", main="Binomial vs Normal")
lines(x, norm, col="red", lwd=2)
legend("topright", legend=c("Binomial", "Normal"), col=c("blue","red"), lwd=2)
```
